# Tech Stack

- Frontend
    - React + Vite + TS
    - Styling : Tailwind
- Backend
    - FastAPI
    - Database : PostgreSQL
    - Auth : JWT (Ignored first for MVP, to be implemented separately later on)
    - Hosting : Amazon EC2 later (But locally for MVP for now)
- Sign language capture:
    - Model : TFlite model (Has been trained and will just be included in the backend repository)
    - Sign langauge recognition : Using Mediapipe hollistic solutions (Both pose and hand landmarks)
